# FastDB 2.7.0: report the engine release

User-authorized 2026-10-15: tools such as Studio show which FastDB release
serves a database. Linux x64; all seven native clients. The catalog format and
stored data are unchanged; previous artifacts stay immutable.

## Engine and clients

- [x] `fastdb_version()` returns the engine release from SQL. It is registered
  with the FastDB frontend functions (no core change) and is not deterministic,
  so CHECK, computed fields and index expressions reject it.
- [x] `fastdb --version` and `-V` print `fastdb VERSION` from both binaries.
- [x] The local service details reply and the embedded Node adapter report
  `engineVersion`; Node types it as optional because older services omit it.
- [x] Cloud details report `engineVersion` (2.5.3, Worker `08265f94`, fastdborg/cloud#22);
  `fastdb_version()` reaches Cloud with its next engine upgrade.

## Release

- [x] Full scoped checks on the version-aligned source: 1,097 Rust, 188 Node, five C ABI,
  two release-policy and three upgrade-table tests; four opt-in measurement tests

- [x] Notices and RustSec review (359 shipping packages, zero unresolved findings).
- [x] Upgrade dry run (12 checks on Node 22 and 24), exact-source CI, production
