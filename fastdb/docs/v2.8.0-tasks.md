# FastDB 2.8.0: join collections with relational tables

User-authorized 2026-10-15: a relational table that stores a document's record
ID as text (`posts.user_id = 'users:tan'`) joins that collection with the plain
`ON u.id = p.user_id` form. Linux x64; all seven native clients. The catalog
format and stored data are unchanged; previous artifacts stay immutable.

## Language

- [x] `=`, `!=`, `IS`, `IS NOT` between a document field and a relational column,
  and `IN`/`NOT IN` subqueries across the two kinds of source, treat TEXT written
  as a record ID as that record. Other values and NULL results are unchanged; a
  collection `id` comparison keeps a hash join or key lookup.
- [x] Unqualified names in collection joins resolve to the only collection's
  field when no relational source has that column; relational column names stay
  ambiguous unless every collection is strict without that field; the bare
  collection alias returns its whole document.
