# FastDB 2.6.0: warm Cloud databases and connect without a round trip

User-authorized 2026-10-15: changes that help every Cloud user. Linux x64; all
seven native clients. The engine, catalog format and service protocol for local
databases are unchanged; previous artifacts stay immutable.

## Clients

- [x] Node `connect()` on a Cloud database URL skips the details request by
  default; `deferInfo: false` restores the 2.5 behavior. Code that calls
  `prepareWrite` right after connecting must read, call `info()` or pass
  `afterSequence` first; `writeAtomic` fetches the details itself.
- [x] Node `connect()` on a Cloud URL sends a warm request in the background
  (`warm: false` skips it); `db.warm()` returns `ready`, `starting` or `skipped`.
- [x] CLI `db warm UUID`; interactive `db access` warms in the background when
  stdin is a terminal.
