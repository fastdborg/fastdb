# FastDB 2.5.1: spatial follow-up, Cloud and Studio

User-authorized 2026-10-13: close the remaining spatial upgrade items, then bring
the released engine to Cloud and add spatial support to Studio. Linux x64; all
seven native clients. No catalog format change; previous artifacts stay immutable.

## Engine

- [x] Nearest search with rare filters: rounds stop once the observed match rate
  shows that one scan is cheaper, and the distance guard runs last in that scan.
- [x] Scalar indexes: spatial rewrites and nearest search count both candidate
  sets and use the smaller one; a spatial rewrite no longer drives the statement
  from a scalar index scan.
- [x] Metered reads charge nearest rounds, probes and bounded counts.
- [x] Field reads scan the canonical stored layout and stop at the member;
  encoded accessors return the stored bytes; eight parsed field paths are cached.
- [x] Nearest interruption (cancellation and deadline), result-limit and `k`
  limit tests.
- [x] Interrupted `REINDEX` of a latitude-format spatial index leaves the old index intact.
- [x] Acceptance ceilings for the selective fixtures, asserted in tests and recorded
  in the [evidence](spatial-upgrade-evidence.md#frozen-work-ceilings).
- [x] Concurrent movement and search benchmark with recorded budgets
  (`scripts/bench-spatial-movement.cjs`).
- [x] Polygon value round trips and spatial queries in the shared native client
  fixture (110 steps in PHP, Go, C# and Swift; tagged steps in Python and Node).
- [x] Bounded randomized stress test comparing indexed results with scans across
  inserts, updates, deletes, rollbacks, seams and poles.
- [x] `geo::cell_cover` decision and profile counter coverage recorded in the
  [contract](spatial-upgrade.md#9-profiles).
- [x] Per-row cost for large result sets measured and reduced.
- [x] Plan and checklist records reconciled with linked evidence.
- [x] `INFO` reports spatial index geometry (point or region) and storage format.
- [x] 2.5.0 to 2.5.1 upgrade/restore check (`scripts/check-v251-upgrade.cjs`);
  2.5.0 reads files written by 2.5.1.
