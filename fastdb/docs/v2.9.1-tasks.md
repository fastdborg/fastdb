# FastDB 2.9.1: Turso 0.8.3 engine

User-authorized 2026-10-20: release the merged Turso 0.8.3 engine sync
(fastdborg/fastdb#30) as a patch release, then move FastDB Cloud to it. 2.9.0 is
already published and stays immutable. Linux x64; all seven native clients. The
catalog format and stored data are unchanged.

## Engine

- [x] Turso 0.8.3 (`607bff9fd0e547a25a97b3bf06e83bcc5d99d53c`): MVCC durability
  fixes, AUTOINCREMENT no longer reuses an explicit id 1, and `PRAGMA journal_mode`
  refuses MVCC switches inside a transaction. All eight engine exceptions kept.
  See [the sync notes](turso-0.8.3.md) and [checklist](turso-0.8.3-tasks.md).

## Release
