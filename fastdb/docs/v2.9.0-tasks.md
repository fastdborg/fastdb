# FastDB 2.9.0: Cloud query version 3

User-authorized 2026-10-16 (FastDB Cloud production limits, item 8): the Node SDK
and CLI speak Cloud query version 3, in which Binary and Vector values travel as
base64 and `/query` and `/read` bodies may be up to 1 MiB. Cloud keeps accepting
2.8.0 clients on version 2. Linux x64; all seven native clients. The catalog
format and stored data are unchanged; previous artifacts stay immutable.

## Language

- [x] A relational query whose subquery reads a document table returns its
  unaliased columns under their own names; keyword names such as `plan` or `key`
  used to come back quoted (`"plan"`), found in FastDB Cloud's metadata.

## Clients

- [x] Node SDK: Cloud URLs send `x-fastdb-query-version: 3`, encode Binary and
  Vector parameters as canonical base64 and allow 1 MiB request bodies; local
  services and embedded databases keep version 2 and 64 KiB. Responses decode
  byte arrays and base64. Saved writes are version 2 and record their query
  version; version 1 saved writes replay at version 2. Journals up to 2.25 MiB.
- [x] CLI: Cloud reads and queries send version 3 and allow 1 MiB; new journals
  are version 4 (query) and 5 (read); 2.8.0 journals replay without the header.
