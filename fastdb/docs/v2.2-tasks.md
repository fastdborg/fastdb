### Initial ANN backlog research, 2026-10-02 (superseded below)

- Pinned USearch 2.26.2 source exposes `filtered_search` with a key predicate,
  scalar quantization and buffer serialization. Current FastDB deliberately
  pins F32 in both catalog identity and graph validation; compressed graphs
  therefore need explicit metadata, accuracy/integrity and persistence evidence.
- [Official Rust documentation](https://unum-cloud.github.io/USearch/rust/index.html)
  describes memory-mapped external files and buffer views. External index files
  do not participate in FastDB's current single-file WAL/backup transaction.
  This is an architecture constraint to evaluate, not permission to ship an
  untracked sidecar or substitute an unindexed scan.
- [TurboQuant paper](https://arxiv.org/abs/2504.19874), read 2026-10-02: random
  rotations with scalar quantization target geometric distortion; the
  inner-product variant additionally quantizes residuals. These are distinct
  codecs and distance kernels, not an alias for native USearch F16/I8 storage.
  Research claims are not FastDB benchmark or compatibility evidence.

- Baseline addon SHA-256

  rejects fourth-argument text/vector filters with
