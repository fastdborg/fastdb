# FastDB 2.5.3: faster scans and grouping

User-authorized 2026-10-14: make collection scans and grouping cheaper per
document and release the result as 2.5.3. Linux x64; all seven native clients.
No catalog format change; previous artifacts stay immutable.

## Engine

- [x] Field reads parse null, boolean, integer, number and escape-free string
  members directly; other members still use the JSON decoder.
- [x] Spatial and other helpers decode canonical points and scalars directly and
  read their arguments in place.
- [x] Grouped collection queries evaluate field accessors before grouping, so the
  GROUP BY sorter holds extracted values instead of whole documents.
- [x] A larger default page cache was measured and not adopted: a ten-times larger
  cache gave 4 to 10% on a 65 MB file-backed scan.
- [x] Tests compare the direct parsers with the JSON decoder and 14 grouped query
  shapes with and without the rewrite.

## Release process

- [x] Release upgrade checks driven by one version-range table, with a dry run
  before tagging (PR 22); 2.5.3 adds one row for 2.5.2.

## Release

- [x] Full scoped checks on the version-aligned source: 1,093 Rust, 185 Node, five C ABI,
  two release-policy and three upgrade-table tests; four opt-in measurement tests
  are ignored by design.
- [x] Notices and RustSec review (359 shipping packages, zero unresolved findings).
- [x] Upgrade dry run, exact-source CI, production bundle and installed
  verification groups, including 2.5.0, 2.5.1 and 2.5.2 → 2.5.3.
- [x] Before/after measurements ([evidence](spatial-upgrade-evidence.md#253-scans-and-grouping)).
- [x] SurrealDB comparison with the release package, recorded on `main` after
  publication ([comparison](spatial-surrealdb-comparison.md)): cell counts 29%
  and the 0.1% fleet scan 23% faster than 2.5.1; results matched in every sample.
- [x] Release records, tag `fastdb-v2.5.3` on the build commit, publication and
  independent download verification ([receipt](release-2.5.3-download.json)).

Cloud and Studio are not part of this release.
