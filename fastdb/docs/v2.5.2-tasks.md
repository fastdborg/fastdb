# FastDB 2.5.2: EXPLAIN reads no data

User-authorized 2026-10-14: make spatial EXPLAIN read no customer data (option C
of the Cloud 2.5.1 finding), release the engine patch and restore Cloud's
zero-read EXPLAIN rule. Linux x64; all seven native clients. No catalog format
change; previous artifacts stay immutable.

## Engine

- [x] EXPLAIN of ordinary nearest statements shows the first round at the nominal
  100 m radius without the index-only radius search.
- [x] EXPLAIN skips the scalar-index and candidate counts of the spatial planner.
- [x] EXPLAIN of `search::nearest` describes its first index round instead of
  running it.
- [x] Metered EXPLAIN reports zero rows read for every spatial form
  (`spatial_explain_reads_no_documents_or_index_entries`); it read 66 to 3,041
  rows in 2.5.1.
- [x] Contract records that EXPLAIN shows the spatial plan and that data-dependent
  choices happen only at execution.
