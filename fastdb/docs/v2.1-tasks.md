# FastDB / FastQL 2.1 production checklist

User-approved objective: production release for V2, version 2.1.0. Native Linux
x64 only, seven implemented clients. No cloud, browser/WASM or graph database
scope. Preserve SQL joins, typed records, bounded document references and inverse
lookups. Released 2.0.0 and its artifacts remain immutable.

Source, artifact, workload and public-release gates are complete on
`587c3b4afae7382920fcdec64e91b1a97eda6f5a`; see the [measured envelope](production-envelope.md) and
[verified public download](release-2.1.0-download.json). [Exact-source CI 36159249358](https://github.com/fastdborg/fastdb/actions/runs/36159249358)
passes. [The release record](release-2.1.0.md) binds the completed checks to the
source archive, shipping lockfile, build manifest and build checksums.

- [x] P0 artifact qualification: source-preserving SQLite snapshot/adoption CLI,
  supported-schema matrix, four permanent regressions and all 14 stock-SQLite
  fixture groups pass against the exact optimized CLI; importer SQLite 3.53.2.
- [x] P1 artifact qualification: permanent sync/async Node process-ownership
  tests pass against both exact installed Node packages. Linux deployment remains
  one owning process per file with supported connections inside that process.
- [x] P2 source/artifact qualification: optimized native shipping profile retains

  seven clients, Node 22/24 and Python 3.10/3.12/3.14. The exact distributed-source

- [x] P2 workload/resource acceptance: both unchanged exact-artifact workloads

Both completed workload configurations retain 1,000 documents/32 dimensions
and 5,000 documents/128 dimensions, one/four connections, 5,000 mixed
operations, 1,000 concurrent rounds where applicable, and one sample per
connection count. Results and limits are in [the envelope](production-envelope.md).
Public archive and checksum identities are in [the download receipt](release-2.1.0-download.json).

Each completed entry records its exact source/artifact evidence. Implementation
checks do not imply final artifact qualification. Online backup, registry
publication, new platforms, graph APIs and driver-standard adapters are outside
this finite release gate.
